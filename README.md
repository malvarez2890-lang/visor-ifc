# Visor IFC

Visor de modelos IFC que funciona en el navegador (computador, tablet y celular).
El archivo se procesa en el equipo de quien lo abre: no se sube a ningún servidor.

- Vistas isométrica, planta, frente y lateral; corte horizontal; medición.
- Lista por clases IFC con ocultar/mostrar, buscador y ficha de propiedades de cada pieza.
- Abre archivos `.ifc` (STEP). No abre `.ifcZIP` ni `.ifcXML`.

Usa [three.js](https://threejs.org) y [web-ifc](https://github.com/ThatOpen/engine_web-ifc) (incluidos en `vendor/`).
